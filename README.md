# ChRG+ Hub | Interactive Clustering Analysis Platform

[ChRG+ Hub](https://people-gfhw.onrender.com/) is an interactive web platform developed as the practical component of my Master's thesis at the University of Coimbra.

The project presents **ChRG+**, a hierarchical clustering algorithm designed to handle datasets with complex geometric structures and high levels of noise. The platform combines theoretical concepts with an interactive experimentation environment, allowing users to generate synthetic datasets, execute clustering algorithms, and visually analyze their behavior in real time.

The application was designed both as a research support tool and as an educational environment for exploring clustering techniques and their limitations under different data distributions.

## Features

* **Interactive Execution & Visualization:** Real-time execution and visualization of clustering algorithms.
* **Algorithm Comparison:** Real-time comparison between ChRG+ and traditional clustering methods.
* **Synthetic Data Generation:** Synthetic dataset generation with configurable parameters.
* **Dynamic Graphical Analysis:** Graphical analysis of clustering behavior on noisy and non-linear datasets.
* **Web-Based Environment:** Experimentation environment focused on accessibility and usability.
* **Integrated Content:** Presentation of both theoretical and practical aspects of clustering analysis.

## Technologies Used

* **Backend:** Python, Flask
* **Frontend:** HTML, CSS, JavaScript
* **Deployment:** Render
* **Database / Storage:** PostgreSQL (Neon)

## Future Improvements

Although the platform is fully functional, several improvements are planned for future development:

* Refactor the application into a more modular and maintainable architecture.
* Improve separation of responsibilities through better class and component organization.
* Optimize server-side processing and clustering execution performance.
* Add support for additional clustering algorithms and benchmarking tools.
